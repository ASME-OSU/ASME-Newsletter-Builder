How to Use the Builder

A new-officer guide to building, checking, and sending an ASME newsletter.

  1. Start with a layout

    Choose Templates for a starter layout, or Tools → New Issue for a fresh issue. Your draft saves automatically in this browser.

  2. Choose your events

    Search Calendar, tick the events for this issue, then choose Import selected. Select all selects the events shown, excluding ones already imported. Date filters are under More filters & tools.

  3. Make it your own

    Edit event copy, then use Actions → Use as featured for your highlight. Complete or switch off Featured, Announcement and Quick Links. Add alt text to images.

  4. Write for the inbox

    Add your subject and preheader in Settings. In Design, choose the email appearance and check the chapter mailing address. Save organization defaults once for future issues.

  5. Review before sending

    Open Send readiness and use Fix to jump to a field. Check links, then use the preview controls. On phones the email fills the screen; the moon toggles dark simulation.

  6. Copy, test, then send

    Choose Export → Copy HTML for Brevo. In Brevo, start a campaign and choose Design → Code your own. Paste the HTML and send yourself a test before sending to members.

Keep your work: Use Templates → Saved issues to save a named issue, or export a draft to share with another officer. Undo and Revision History recover major changes. A downloaded HTML file is a finished preview, not an editable draft. Dark simulation is approximate; use a Brevo test to check the actual email.
